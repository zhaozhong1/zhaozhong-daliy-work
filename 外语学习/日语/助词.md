### 1. **格助词**

表示名词与动词或其他词的关系。

| 助词   | 主要功能         | 示例                               | 解释                     |
| ------ | ---------------- | ---------------------------------- | ------------------------ |
| **は** | 主题标记         | 私は学生です。                     | 我是学生。               |
| **が** | 主语标记         | 猫がいます。                       | 有一只猫。               |
| **を** | 动作对象标记     | 本を読みます。                     | 读书。                   |
| **に** | 时间、地点、目标 | 1時に会います。学校に行きます。    | 在1点见面。去学校。      |
| **へ** | 方向             | 日本へ行きます。                   | 去日本。                 |
| **で** | 动作地点、手段   | バスで行きます。学校で勉強します。 | 坐公交车去。在学校学习。 |

------

### 2. **副助词**

表示附加意义，强调、限定等。

| 助词       | 主要功能             | 示例                 | 解释                   |
| ---------- | -------------------- | -------------------- | ---------------------- |
| **も**     | 也、都               | 私も学生です。       | 我也是学生。           |
| **だけ**   | 仅仅、只有           | 本だけ読みます。     | 只看书。               |
| **しか**   | 除了……都不（带否定） | 本しか読みません。   | 只看书（其他都不看）。 |
| **ばかり** | 几乎、只             | 食べてばかりいます。 | 总是在吃东西。         |

------

### 3. **接续助词**

连接句子或词语，表示前后关系。

| 助词              | 主要功能       | 示例                             | 解释                 |
| ----------------- | -------------- | -------------------------------- | -------------------- |
| **から**          | 表原因、起点   | 雨だから行きません。             | 因为下雨，所以不去。 |
| **ので**          | 表原因（柔和） | 天気がいいので行きます。         | 因为天气好，所以去。 |
| **けど** / **が** | 转折、对比     | 日本語が難しいけど、面白いです。 | 日语难，但有趣。     |
| **と**            | 条件、引用     | 春になると桜が咲きます。         | 一到春天樱花就开了。 |

------

### 4. **终助词**

用于句尾，表示感情或态度。

| 助词   | 主要功能     | 示例               | 解释           |
| ------ | ------------ | ------------------ | -------------- |
| **ね** | 表同意、确认 | 面白いですね。     | 很有趣吧。     |
| **よ** | 表提醒、告知 | ここは安全ですよ。 | 这里很安全哦。 |
| **か** | 表疑问       | これは何ですか？   | 这是什么？     |

------

### 5. **复合助词**

由多个助词组合而成，用于表达更复杂的语法。

| 助词         | 主要功能     | 示例                         | 解释             |
| ------------ | ------------ | ---------------------------- | ---------------- |
| **について** | 关于……       | 日本の文化について話します。 | 谈谈日本文化。   |
| **によって** | 表方式、原因 | 飛行機によって行きます。     | 乘飞机去。       |
| **のために** | 为了……       | 健康のために運動します。     | 为了健康而锻炼。 |

------

### 6. **区分助词「は」与「が」**

- は

  ：强调主题，与后文关系密切，常用于已知信息。

  - 猫は可愛いです。（猫很可爱——以猫为主题）

- が

  ：强调主语，是句子的核心，常用于新信息。

  - 猫がいます。（有一只猫——新引入的内容）

------

### 7. **助词学习的重点**

- 牢记基础助词的用法，理解其意义。
- 在日常学习中通过例句记忆助词的用法。
- 注意助词的语感，比如「で」和「に」在表达地点时的区别。
