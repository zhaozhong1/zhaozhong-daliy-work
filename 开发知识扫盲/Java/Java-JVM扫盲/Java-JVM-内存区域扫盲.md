# JVM内存区域扫盲

## 详细介绍JVM内存区域

JVM内存区域分为运行时数据区域和本地内存。

### 线程共享区域(运行时数据区域)

线程共享区域就是线程可见的内存区域。

#### 堆区

堆区是存放对象的区域。在JDK1.7中，堆区开始包含字符串常量池。

#### 方法区

方法区在JDK1.7时存放在运行时数据区域的线程共享区域，此时方法区叫做永久代，存放的是类信息。

在JDK1.6时，字符串常量池包含在方法区中。

### 线程私有区域(运行时数据区域)

#### 虚拟机栈

虚拟机栈中存放在线程中声明的局部变量。×

虚拟机栈是一个栈结构，存放着一个个栈帧。

##### 虚拟机栈-栈帧详细：*

栈帧包括：

1. 局部变量表：存放基本数据类型和引用类型。通过索引访问。
2. 操作数栈：主要作为方法调用的中转站使用，用于存放方法执行过程中产生的中间计算结果。另外，计算过程中产生的临时变量也会放在操作数栈中。
3. 动态链接：动态链接的作用就是为了将符号引用转换为调用方法的直接引用，这个过程也被称为**动态连接** 。
4. 方法返回地址：即存放调用该方法的地址。

#### 本地方法栈

本地方法栈存放使用JNI调用本地方法的局部变量。

#### 程序计数器

程序计数器用于切换线程时恢复到该线程执行的指令。

### 本地内存(线程共享)

#### 直接内存 *

直接内存是一种特殊的内存缓冲区，并不在Java堆或方法区中分配，而是通过JNI的方式在本地内存上分配。

#### 方法区

方法区在JDK1.8后存放在本地内存当中。此时方法区叫做元空间，即存放类的元数据。
