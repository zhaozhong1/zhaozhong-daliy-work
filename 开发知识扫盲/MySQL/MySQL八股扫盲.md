# MySQL基础扫盲

## MySQL 查询 执行流程

### 1. 连接

客户端通过JDBC的驱动连接MySQL的连接器。这个过程是基于TCP的。

### 2. 查询缓存

MySQL会先从自身的缓存中查询是否存在可以直接获取的数据。有的话就直接返回，没有就走接下来的流程。

### 3. 分析器

分析器包含词法分析和语法分析。

- 词法分析是对sql语句进行解析，解析出非关键字和关键字。
- 语法分析是根据词法分析的结果，分析是否符合mysql语法，没问题则构造出语法树。

### 4. 执行

分析出语法树后，开始执行语句。

1. 首先会进入**预处理阶段**，预处理将检查语法树中的表和字段是否存在，存在的话，如果有*，则扩展为全部字段。
2. 然后进入**优化器**进行优化。优化器会为该sql基于查询负载来选择最优的执行计划。
3. **执行器**获得执行计划，开始执行。执行是通过访问数据存储引擎来执行的。
